# Instrucciones para el agente (Octavio Android)

Proyecto: asistente Tamagotchi para Android (Nothing Phone 2a). Bicho pixel art
en live wallpaper conectado a Hermes (perfil `tamagotchi`) vía Tailscale.

## Stack

- Kotlin nativo (NO Compose Multiplatform). Live wallpaper = `WallpaperService`.
- Gradle 8.11.1 (wrapper), AGP 8.7.3, Kotlin 2.0.21.
- compileSdk 35, minSdk 26, targetSdk 35. JDK 21, bytecode Java 17.
- Dependencias mínimas: solo `androidx.core:core-ktx` en Fase 1.

## Comandos

```bash
./gradlew assembleDebug        # compilar APK de debug
./gradlew test                 # tests (cuando existan)
~/Android/platform-tools/adb install -r app/build/outputs/apk/debug/app-debug.apk
~/Android/platform-tools/adb logcat -s Octavio   # logs (si añadimos tags)
```

## Reglas del proyecto

- Estado del bicho = timestamps de último evento, valores derivados del tiempo
  (mismo patrón que el ESP32). NO guardar valores "actuales" en un proceso vivo.
- Comunicación con el usuario en español.
- Commits atómicos, mensaje en español.
- `local.properties` NO se commitea (apunta a `sdk.dir=/home/liberto/Android`).
- Cualquier arte de pixel art nuevo se añade a `PetSprites.kt` (constantes) y se
  regenera el PNG de referencia con `scripts/gen_sprites.py`.

## Roadmap

- Fase 1: bicho + animación + toques + persistencia (actual).
- Fase 2: STT/TTS local (sherpa-onnx) + bridge FastAPI → Hermes vía Tailscale.
- Fase 3: app como asistente por defecto (VoiceInteractionService).
- Fase 4: LLM local (llama.cpp 1-2B) como fallback offline.
